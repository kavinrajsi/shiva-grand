# Shiva Grand Residency

Static marketing website for Shiva Grand Residency — a hotel in Coimbatore.

## Pages

| File | Purpose |
| --- | --- |
| `index.html` | Home — hero, location, rooms preview, amenities |
| `book-you-stay.html` | Rooms / Book Your Stay |
| `booking.html` | Booking request confirmation |
| `local-guide.html` | Local guide to Coimbatore (food, parks, shopping) |
| `blog.html` | Blog listing |
| `blog-detail.html` | Blog article detail |
| `contact-us.html` | Contact information |

## Tech

Plain HTML with Tailwind CSS utility classes (loaded via CDN). No build step.

## Running locally

Open `index.html` directly in a browser, or serve the directory with any static server:

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```
