# shiva-grand

Next.js 16 starter for the Shiva Grand Residency website.

## Stack

- **Next.js 16.2.6** — App Router, Turbopack, React Compiler enabled
- **React 19.2.4**
- **JavaScript** with `jsconfig.json` (path alias `@/* → src/*`)
- **Tailwind CSS v4** (CSS-first config via `@tailwindcss/postcss`); CSS Modules also available
- **Manrope** via `next/font/google` (weights 200–800)
- **Material Symbols Outlined** via `next/font/local` (bundled from the `material-symbols` npm package)
- **ESLint 9** flat config (`eslint-config-next/core-web-vitals`)

## Getting started

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Edit `src/app/page.js` — the page auto-reloads on save.

## Scripts

| Script          | Description                          |
| --------------- | ------------------------------------ |
| `npm run dev`   | Start the dev server (Turbopack)     |
| `npm run build` | Production build                     |
| `npm run start` | Serve the production build           |
| `npm run lint`  | Run ESLint                           |

## Project layout

```
src/app/        App Router routes (server components by default)
  layout.js     Root layout — registers Geist font variables
  page.js       Home page
  globals.css   Global styles
public/         Static assets served at /
types/          Auto-generated by Next.js — do not edit
next.config.mjs Next.js config (React Compiler enabled here)
postcss.config.mjs Tailwind v4 PostCSS plugin
eslint.config.mjs Flat ESLint config
jsconfig.json   Path aliases
```

## Environment

Create `.env.local` at the project root. It is gitignored.

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
SUPABASE_SERVICE_ROLE_KEY=

# Resend (email)
RESEND_API_KEY=
RESEND_FROM_EMAIL=
ADMIN_EMAIL=
EMAIL_CC=                  # optional, comma-separated
EMAIL_BCC=                 # optional, comma-separated

# Sanity CMS
NEXT_PUBLIC_SANITY_PROJECT_ID=
NEXT_PUBLIC_SANITY_DATASET=production
SANITY_API_TOKEN=
```

Vars prefixed `NEXT_PUBLIC_` are exposed to the browser. Everything else stays on the server — never reference them from client components.
